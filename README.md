# Blinky

Simple Blinky example for using a layer architecture (application, device and hardware layer).
You will find (work in progress) multiple hardware layers for different uC to select from.
No RTOS is used in this example.

## Supported hardware:
* STM32L476RG
* Pico RP2040 (work in progress)
